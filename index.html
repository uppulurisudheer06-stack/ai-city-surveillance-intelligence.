01 / Project Overview

Introduction

Urban environments generate large amounts of visual information. Manually monitoring every camera feed can be time-consuming. This project explores how computer vision and deep learning can support the analysis of city surveillance images and videos.

◎ Problem Statement

To develop an application that uses object detection models to analyse visual input and identify selected events, helping users review surveillance content more efficiently.
